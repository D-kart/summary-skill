## 2. 单元格改写规范

> 表格每格的目标产出形态是"**3–6 条要点，每条 1 句话**"，不是大段散文。

### 改写动作
1. **同主题事实合并**：同一维度下的多条 facts 合并表述；冗余删除。
2. **口语 → 书面**：去掉"我们""你看""那个谁"等口语；写成第三人称陈述句。
3. **保留关键定量信息**：数字、客户名、产品名、技术路线一律保留原文。
4. **多人观点归属**：同一维度下不同讲话人的不同观点写成 `A 总补充：xxx` / `B 总另认为：xxx`；推断不出来用 `对方补充：xxx`。
5. **后续追问建议（可选）**：维度访得不够深时，可在该单元格末尾加一行 `（建议下轮补充：xxx）`。

### 单元格风格示例

✅ 好：
```
- 主营储能系统集成，产品覆盖电芯、PCS、EMS；客户以国央企电力公司为主，2025 年向独立储能业主拓展。
- 商业模式以 EPC + 后期运维服务为主；自有运维平台覆盖蒙西、阿克苏在运电站。
- A 总补充：今年新增"大客户直供"模式，向远景、海博思创等系统集成商配套核心部件。
```

❌ 差：
```
关于公司是做什么的这个事情，对方在访谈中提到他们主要是做储能的，然后呢说客户主要是一些电力公司，
然后他们的商业模式是用 EPC 加运维这样的方式来做的，A 总也补充说……
```

### 未涉及维度的写法

- **完全未涉及**：
  ```
  本次访谈未涉及，建议下轮补充。
  ```
- **提到但缺关键细节**：
  ```
  对方提及上轮融资 2024 年完成，金额、估值与投资方未披露；建议下轮要 capdoc 与 SHA。
  ```

> 不留空单元格，不写"无"或"N/A"——会被外部读者误解为不重要。

## 3. 核心观点摘要（提炼 3–6 条）

完成 20 个维度填充后，挑出全场最重要的 3–6 条论断，准备放进**表后的"核心观点"段**。

挑选标准：
- 影响投资决策的关键判断（市场规模、技术路线代差、客户结构、估值预期）
- 高信息密度的定量数据（市占率、营收、毛利率、产能、IRR 等）
- 真正的差异化信息（公开材料 / 招股书 / 公告里查不到的）

写法：每条 1–2 句话，定量信息优先。

✅ 好：
```
1. 公司今年储能出货 3 GWh，明年规划 5–6 GWh，对应营收量级约 xx 亿元（口径未明确）。
2. 蒙西模式（独立储能电站）补贴 0.35 元/kWh，IRR 区间 10–20%，是公司当前最赚钱的业务形态。
3. 电芯供应受 314Ah → 500Ah 大电芯路线切换影响，2026 年上半年存在结构性紧缺。
```

## 4. 后续事项段

逐条列出会议中**口头约定**的后续动作（不要为了凑结构而编）。每条尽量含责任方 + 时点：

```
- 公司方：发送最新版蒙西电站可研与 IRR 测算（本周内）
- 我方：内部讨论是否邀约 CEO + CFO 专项尽调（拟下周决定）
- 双方：约定 2026-Q3 末再做一次行业跟进电话
```

> 没有任何后续事项就**整段省略**，不要为了凑结构而写"无"。

## 5. 完成标志

- 20 个维度的单元格内容全部就绪（包括未涉及维度的写法）。
- 单元格内容是要点形态、不是散文。
- 核心观点摘要 3–6 条。
- 后续事项段已就绪（或确认确实没有，整段省略）。
- 所有内容用第三人称陈述句、客观中性；零口语、零口癖、零内部黑话。
