# Step 1 · 清洗与抽取

> 拿到原始转写后的**第一步**。把"录音转文字"的脏数据清掉，把核心事实抽出来。

## 1. 转写文本的典型脏数据

| 脏数据特征 | 处理方式 |
|---|---|
| 口癖：那个、就是、然后、对吧、嗯、啊 | 一律删除 |
| 重复：同一句话连说两遍 | 取一遍 |
| 自我修正：说错重说 | 取最终版本，过程性话语丢弃 |
| 同音错别字：金鹰→金融、共因→工艺 | 按上下文推断纠正 |
| 关键名词存疑：客户名、人名拼写不一致 | 全文统一为最频繁/最可信的写法；存疑的标 `(原文如此)` |
| 数字单位省略："5 个"/"一两千"/"差不多" | 按上下文补单位；无法确定的标 `(单位待核实)` |
| 多人对话插话、谁说的不清 | 按称呼、上下文、身份推断；推断不出来用"对方补充" |
| 寒暄、客套、跑题 | 不抽取，不进入 facts |

## 2. 抽取目标：事实片清单

把对话流切成 40–150 条事实片。每条结构：

```yaml
- id: F001
  raw_quote_cleaned: "今年公司储能出货预计 3 GWh，明年规划 5–6 GWh"
  speaker: "对方"          # A总 / B总 / 我方 / 对方（推断不出来时）
  category: "财务"          # 行业 / 团队 / 产品业务 / 财务 / 风险 / 其他
  dim_id: "4.1"            # 对应 20 个维度的编号
  key: "出货量"
  value: "今年 3 GWh，明年 5–6 GWh"
  confidence: high          # high / medium / low
  note: ""                  # 必要时补一句上下文说明
```

> 这是中间产物，不交付给用户。

## 3. 抽取分类清单

### 行业类（对应维度 1.1–1.4）
- 主营业务（做什么 / 卖给谁）
- 行业名称、细分赛道、TAM / SAM / SOM
- 市场痛点
- 行业政策 / 监管动态
- CR3 / CR5 / 主要竞品名单
- 公司在行业中的位置（市占率 / 排名）
- 公司竞争优劣势的具体描述

### 团队类（对应维度 2.1–2.5）
- 实控人姓名、履历、过往创业经历
- 管理层名单（CTO / COO / CFO / VP-Sales 等）及履历
- 员工总数、研发占比、销售占比
- 股权结构、持股比例、是否代持、期权池
- 公司战略目标（量化指标）

### 产品业务类（对应维度 3.1–3.5）
- 产品 / 服务清单
- 各业务线收入占比、市场策略（直销 / 经销 / 代理）
- 核心技术路线、与竞品的技术差异
- 研发里程碑、未来 12 个月路线图
- 当前 / 在建 / 规划产能、良率
- TOP 5 客户名单及合同情况
- 核心供应商、议价能力、是否单源风险

### 财务及融资类（对应维度 4.1–4.5）
- 历史营收（含 / 不含税要标注）
- 收入预测及假设
- 毛利率 / 净利率
- 各业务线 / 客户行业的收入占比
- 现金及现金等价物余额、跑道
- 历史融资轮次（时间 / 估值投前投后 / 金额 / 领投跟投）
- 本轮融资计划（金额 / 估值 / 用途）
- 上市规划 / 中介机构 / 对赌条款

### 风险类（对应维度 5.1）
- 核心人员风险
- 大客户集中度
- 供应链单源风险
- 政策 / 合规风险
- 技术路线风险
- 诉讼 / 仲裁、知识产权纠纷
- 股权代持 / 一致行动隐性问题

## 4. 抽取硬性规则

1. **原话先清洗、再抽取**：清洗只动口癖 / 重复 / 错别字 / 单位补全，**不修改对方的实质表述**。
2. **数字必带单位**：5 → 5 亿元 / 5 万台 / 5%。
3. **客户名 / 产品名 / 技术名**保留对方原称，全文统一拼写。
4. **不确定的事实** `confidence: low`，note 字段标疑点。
5. **同一事实被多人不同口径描述**：分别记录为多条 facts，speaker 字段区分。
6. **明显的口误 / 自我修正**：以对方最终确认的版本为准。
7. **寒暄 / 跑题 / 重复**不进 facts。
8. **后续事项 / 口头承诺**单独打 `category: "其他"`, `dim_id: "followup"`，留到 Step 2 统一处理。

## 5. 不做什么

- ❌ 不做评价（note 里不写"这个数据可疑""比同行高"）
- ❌ 不做计算（5 亿 + 3 亿 ≠ 8 亿，分别记录原话）
- ❌ 不做归纳总结
- ✅ 只做事实抽取

## 6. 完成标志

- 所有"对方说过的、与投资决策相关的事实"都进入了 facts 列表。
- 每条 fact 在原始转写中可定位（或可指明在哪一问/哪一答）。
- 无主观评价、无计算、无归纳。
- 典型数量 40–150 条。
