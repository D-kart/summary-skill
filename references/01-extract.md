# Step 1 · 关键事实抽取 SOP

> 拿到原始转写文本后的**第一步**。把"对话流"切成"事实片"。

## 目标

从口语化、跳跃式的对话中，**结构化抽取**所有与投资决策相关的事实点，原话保留，不解读、不脑补。

## 输入

- 原始转写文本（一段或多段）
- （可选）公司名、访谈时间、参会人员

## 输出

一份**事实抽取草稿**（中间产物，不交付给用户），结构如下：

```yaml
facts:
  - id: F001
    raw_quote: "我们去年营收差不多 5 个亿"
    speaker: "A总"
    timestamp: "00:03:21"
    category: "财务"          # 行业 / 团队 / 产品业务 / 财务 / 风险 / 其他
    key: "营收"
    value: "约 5 亿元"
    confidence: high          # high / medium / low
    note: "未说明含税口径"
```

## 抽取清单（按类别）

### 🔵 行业类
- 行业名称、细分赛道、TAM / SAM / SOM
- 市场痛点描述
- 行业增速预测
- CR3 / CR5 / 主要竞品名单
- 行业政策 / 监管动态
- 公司在行业中的位置（市占率 / 排名）

### 🔵 团队类
- 实控人姓名、履历、过往创业经历
- 管理层名单（CTO / COO / CFO 等）
- 员工总数、研发占比
- 股权结构、持股比例、是否代持
- 期权池
- 公司战略目标（量化指标）

### 🔵 产品业务类
- 产品 / 服务清单
- 技术路线、核心专利
- 研发里程碑、未来路线图
- 产能、良率
- TOP 5 客户名单及合同情况
- 核心供应商
- 销售模式（直销 / 经销 / 代理）

### 🔵 财务类
- 历史营收（含 / 不含税要标注）
- 收入预测及假设
- 毛利率 / 净利率
- 各业务线 / 客户行业的收入占比
- 现金及现金等价物余额、跑道
- 应收账款 / 存货周转
- 历史融资轮次（时间 / 估值投前投后 / 金额 / 领投跟投）
- 本轮融资计划（金额 / 估值 / 用途）
- 上市规划 / 中介机构 / 对赌条款

### 🔵 风险类
- 核心人员风险
- 大客户集中度
- 供应链单源风险
- 政策 / 合规风险
- 技术路线风险
- 诉讼 / 仲裁
- 知识产权纠纷
- 股权代持 / 一致行动隐性问题

## 抽取规则（硬性）

1. **原话保留**：`raw_quote` 字段必须是对方原话的截取片段，**不要改写**。
2. **数字带单位**：5 → 5 亿元 / 5 万台 / 5% — 必须带单位，否则失去意义。
3. **客户名 / 产品名 / 技术名**保留对方原称，不要替换成通用名词。
4. **不确定的事实**`confidence: low`，并在 `note` 字段标注疑点。
5. **同一事实被多人不同口径描述**：分别记录为多条 facts，speaker 字段区分。
6. **明显的口误 / 自我修正**：以"对方最终确认的版本"为准，原口误版本不抽取。
7. **寒暄 / 重复 / 与业务无关的内容**直接跳过，不进入 facts 列表。

## 边界

- ❌ 不做评价（不要在 note 里写"这个数据可疑""比同行高"）
- ❌ 不做计算（5 亿 + 3 亿 ≠ 8 亿，分别记录原话）
- ❌ 不做归纳（"对方提到产能、客户、研发——综合看公司很扎实" ← 禁止）
- ✅ 只做事实抽取，不做判断

## 完成标志

- 所有"对方说过的、与投资决策相关的事实"都进入了 facts 列表。
- 每条 fact 都能在原始转写中找到对应位置（raw_quote 可定位）。
- 无主观评价、无计算、无归纳。
- 抽取草稿数量典型范围：**40-150 条**（视访谈时长而定）。
