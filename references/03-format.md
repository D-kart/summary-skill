# Step 3 · 按模板组装

> 把 Step 2 整理好的内容填入目标版式（`assets/templates/访谈纪要输出格式.docx`），产出 docx + md 双格式。

## 1. 目标版式结构（与模板一致）

```
[标题]    XX公司访谈纪要        ← Heading 2，居中
[元信息]  访谈对象：            ← 4 行普通段落
          时间：
          地点：
          人员：

[主体表]  20 行 × 3 列：
          第 1 列：大类（"1.行业" / "2.团队" / "3.产品业务" / "4.财务及融资" / "5."）
          第 2 列：考察维度（如"主营业务"）
          第 3 列：访谈内容（要点形态）
          ⚠️ 第 4.1 行第 3 列另起一项"各行业的收入占比"
          ⚠️ 第 4.5 行第 3 列另起一项"业绩对赌"
          ⚠️ 第 5 行的第 2 列是"主要风险"

[表后]    （可选）核心观点摘要
          （可选）后续事项
```

## 3. 推荐生成方式：基于模板复制 + 填空

> 不从零搭表——直接以模板 docx 为骨架填内容，最大程度保留版式。
>
> **首选**：使用 skill 自带的工具脚本 `scripts/build_minutes.py`，调用 `build_minutes(company, meta, rows, key_points, followups, out_dir)` 即可一键生成 docx + md 双产出，省去手写 python-docx 的所有细节。

### 工具脚本调用示例

```python
import sys
sys.path.insert(0, "/Users/<user>/.workbuddy/skills/summary-skill/scripts")
from build_minutes import build_minutes

result = build_minutes(
    company="星辰新能",
    meta={"访谈对象": "...", "时间": "...", "地点": "...", "人员": "..."},
    rows=[...],              # 20 条字符串，顺序见 SKILL.md 第 6 节
    key_points=[...],        # 可选，3–6 条
    followups=[...],         # 可选，含责任方/时点
    out_dir="output/星辰新能访谈纪要",
)
print(result)  # {"docx": "...", "md": "..."}
```

### 如果不能用脚本，手写 python-docx 的关键点

```python
from docx import Document
from copy import deepcopy
from pathlib import Path

TEMPLATE = Path.home() / ".workbuddy/skills/summary-skill/assets/templates/访谈纪要输出格式.docx"

def build_minutes(company, meta, rows_3rd_col, key_points=None, followups=None, out_path=None):
    """
    company        : "星辰新能"
    meta           : {"访谈对象": "...", "时间": "...", "地点": "...", "人员": "..."}
    rows_3rd_col   : List[str]，长度 20，按 SKILL.md 第 6 节顺序对应每一行表格第 3 列的内容
    key_points     : Optional[List[str]]，3–6 条
    followups      : Optional[List[str]]，每条形如"公司方：xxx（本周内）"
    """
    doc = Document(str(TEMPLATE))

    # 1) 标题
    doc.paragraphs[0].text = f"{company}访谈纪要"

    # 2) 元信息 4 行
    for i, key in enumerate(["访谈对象", "时间", "地点", "人员"], start=1):
        doc.paragraphs[i].text = f"{key}：{meta.get(key, '')}"

    # 3) 表格填第 3 列
    table = doc.tables[0]
    assert len(table.rows) == 20 and len(rows_3rd_col) == 20
    for r, content in enumerate(rows_3rd_col):
        # 注意行 15 / 19 内有"两段"——content 内部用换行分段即可
        cell = table.rows[r].cells[2]
        cell.text = ""  # 清空
        for para_idx, para in enumerate(content.split("\n")):
            if para_idx == 0:
                cell.paragraphs[0].text = para
            else:
                cell.add_paragraph(para)
        # 行 15 / 19 的"第二个子项"对应模板中第 3 列已有的预置文本，按需写入
        if r == 14:  # 行 15 (0-index)
            pass  # 处理"各行业的收入占比"
        if r == 18:  # 行 19
            pass  # 处理"业绩对赌"

    # 4) 表后追加段落
    if key_points:
        doc.add_paragraph("")
        h = doc.add_paragraph("核心观点摘要")
        h.runs[0].bold = True
        for i, kp in enumerate(key_points, 1):
            doc.add_paragraph(f"{i}. {kp}")

    if followups:
        doc.add_paragraph("")
        h = doc.add_paragraph("后续事项")
        h.runs[0].bold = True
        for f in followups:
            doc.add_paragraph(f"- {f}")

    doc.save(out_path)
```

### 实际填充时的细节

- **行 15（4.1 历史收入）**：模板第 3 列预留了"各行业的收入占比"作为独立子项；填充时**两段都要给**——第一段写历史收入与预测，第二段单独写各业务线/客户行业的收入占比。
- **行 19（4.5 上市规划）**：模板第 3 列预留了"业绩对赌"作为独立子项；同样两段都要给——第一段写上市规划与中介机构，第二段单独写业绩对赌条款（或"暂无对赌条款"）。
- **行 20（5. 主要风险）**：模板第 1 列只有"5."这一个标记，第 2 列才是"主要风险"——按模板原样处理。

## 5. 严禁出现的文字（最后核查清单）

按行扫一遍最终 docx 和 md，确保**绝对不出现**以下任何字样：

- `summary-skill` / `纪要官.skill` / `OPC-Studio`
- `本纪要由 ... 整理` / `按 SOP` / `按 4 步` / `v1.0` / `Step 1` 等版本/步骤痕迹
- `时间待核查` / `首次出现` / `（时间戳缺失）` 等内部时间戳标签
- `复核说明` / `内部参考 · 严禁外传` / `CONFIDENTIAL` 等内部水印（除非用户明确要求保留）
- `我们认为` / `值得关注` / `建议跟投` / `不建议参与` 等立场词
- `5 大类 20 小项已全覆盖` / `覆盖度核查` 等内部对账话术

✅ 应该出现的：
- 干净的公司名、客观陈述、定量数据、客户名、技术路线、后续事项
